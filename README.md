# Pai D’Égua — Cardápio Premium Final 00

Projeto estático mobile-first, pronto para GitHub e deploy automático no Netlify.

## Ajustes finais desta versão

- Logo oficial Pai D’Égua aplicada na abertura, cabeçalho, rodapé e ícone.
- Links oficiais do Anota Aí separados por unidade.
- Preços confirmados exibidos nos burgers, acompanhamentos e salada.
- Produtos sem preço confirmado direcionam para o pedido oficial, sem valores inventados.
- Imagem do Smash Burger corrigida com transparência real.
- Promoção de Happy Hour incluída: chopp com 50% OFF todos os dias, das 17h às 20h.
- Instagram oficial da Pai D’Égua e crédito da G Tech Sistemas no rodapé.
- Textos de conversão revisados para o consumidor final.
- Estrutura, responsividade, navegação e efeitos da versão aprovada preservados.

## Estrutura

- `index.html`: página completa e links oficiais.
- `css/styles.css`: visual, responsividade e animações.
- `js/menu.js`: catálogo, preços e descrições.
- `js/app.js`: navegação, intro, modal, vitrines e assistente.
- `assets/brand`: identidade oficial.
- `assets/images`: produtos e promoção otimizados.
- `DEPLOY_GIT_NETLIFY.md`: comandos exatos de atualização.
- `QA_REPORT.md`: validações executadas.

## Publicação

O Netlify está conectado ao repositório GitHub. Após substituir os arquivos no clone local e executar `git push origin main`, o deploy de produção é iniciado automaticamente.
