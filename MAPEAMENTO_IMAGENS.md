# Mapeamento de imagens

As imagens foram geradas exclusivamente a partir dos 12 materiais visuais fornecidos nesta conversa. Não foram usadas fotografias de banco de imagens.

## Como substituir

1. Preserve o caminho e o nome para não editar o código.
2. Mantenha a proporção indicada.
3. Exporte em WebP, exceto QR Code e ícones PNG.
4. Atualize a versão do cache em `sw.js`.

## Observações

- Os arquivos `*-thumb.webp` são carregados na galeria para reduzir consumo de dados.
- Ao abrir o modal, a página em alta definição é carregada.
- Os recortes de produto preservam a fotografia oficial; apenas enquadramento, escala, contraste leve e compressão WebP foram aplicados.
- O QR Code atual aponta para `https://cardapio-premium-g-tech.netlify.app/`. Gere outro QR se o domínio final for diferente.
