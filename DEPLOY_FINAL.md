# Deploy definitivo

1. Extraia o ZIP.
2. Copie o conteúdo da pasta `PAIDEGUA_PREMIUM_FINAL` para o repositório Git, preservando apenas `.git`.
3. Execute `git add -A`, `git commit` e `git push origin main`.
4. O Netlify conectado ao branch `main` publicará automaticamente.
